# Requirements
Lastest Node.js Version

# Run cli
To Run Cli You Need to run these commands

```bash
corepack enable
```
After Run:
```bash
pnpm install
```
Lasty Run:

```bash
pnpm build
```

This Builds n8n now run:
```bash
pnpm start
```

This **Runs n8n** after go to localhost create a account **remember the email and password**, then import or create a workflow set a name for the workflow **remember that name** after run:

If You're on Windows Run:
```bash
cli.bat
```

If You're on Linux or Mac Run:
```bash
cli.sh
```

Then Follow The Steps and you're done...
